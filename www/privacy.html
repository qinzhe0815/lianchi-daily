练吃日课隐私说明

更新日期：2026 年 9 月 29 日。

本机资料与记录

身体资料、计划、饮食、体重、训练记录、外观和对话保存在你的设备。本应用没有账号、广告或行为追踪服务，不自行提供云同步。iOS 使用原生文件保存记录，API Key 使用本机 Keychain。系统备份可能包含记录，Keychain 的 Key 不随本应用的文件快照一起保存。

可选的第三方 AI

你自行选择服务商、接口地址和模型。模型扫描发送 API Key 用于认证；食物估算发送照片或文字及营养目标与已记录摄入；趋势分析发送摄入、消耗、体重和营养目标汇总；助手发送对话，并可能按问题读取身体资料、计划、安排和近期记录；识图发送选中的照片和问题。照片在设备上缩小后发送。

应用在发送前按接口和用途说明数据并征求同意，拒绝后仍可使用本地功能。接收方的保留和处理规则以其隐私政策为准。你可以在“我的 → 隐私与数据”撤销发送授权。撤销或清除本机记录不会删除已经发送给服务商的数据。

其他联网

主动更新节假日会访问公开数据源，安卓检查更新会访问 GitHub Releases。iOS 不下载安装 APK。访问外部视频或网站后，适用该网站的隐私规则。

备份与清除

导出备份默认不包含 API Key，明确勾选“包含大模型接口”才带出。请自行保护和保存备份。你可清除本机资料、记录、Keychain Key 和通知；已经导出的文件不随清除操作删除。

健康信息

本应用为健身执行和记录工具，计算与 AI 结果仅作估算参考，不用于诊断或治疗。疾病、特殊饮食需求和训练限制请咨询专业人员。

联系与反馈

个人学习版本可通过项目问题反馈联系维护者。请勿在公开反馈中上传 API Key 或个人健康记录。
